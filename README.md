## 🚀 Get Started: The "Sports Scout" Sprint
We are currently live with our first major case study: **Sports Classics**. 

Ever wondered if **Victor Frankenstein** has the "clutch gene" for a late-season playoff run? We’ve built the prompts to turn these characters into scouting reports.

### **How to Use This Repo:**
1. **Pick a Source:** Upload a PDF/Epub of a classic to NotebookLM.
2. **Run the Discovery:** Use our prompts in `/01-discovery` to map the "data points."
3. **Apply the Lens:** Copy a prompt from `/02-lenses`.
4. **Generate Audio:** Let the AI "Debate" the character's trade value.
